2 処理の流れ（5ステップ）
1
ASINリスト読み込み
スプレッドシートの入力シートからASIN列を読み込みます。1回のAPIコールで最大10件をバッチ処理し、効率よく取得します。
2
PA-API へリクエスト送信
Amazon Product Advertising API v5 に対してリクエストを送信します。取得リソース: ItemInfo（商品名・説明）、Offers（価格）、Images（画像URL）、VariationSummary（バリエーション）。
3
レスポンス解析・整形
JSONレスポンスから必要フィールドを抽出し、日本語ラベルで整形します。取得できなかった項目は「取得不可」と明記します。
4
エラー・レート制限処理
PA-APIには1秒1リクエストの制限があります。自動的にウェイトを入れ、エラー時はリトライします。失敗したASINは別シートにリストアップします。
5
スプレッドシート・CSV 出力
取得結果を出力シートに書き込みます。ヘッダー行はカスタマイズ可能。CSVダウンロードボタン・Excel出力にも対応（Python版）。
3 規約・安全性（PA-API 正規利用について）
  • ✓
    Amazon 規約に準拠 — Amazon Product Advertising API（PA-API v5）は公式が提供する正規の商品情報APIです。利用規約に沿って使用するため、規約違反にはなりません。
  • ✓
    スクレイピング不使用 — Webページへの無断アクセスや HTML 解析は一切行いません。すべてAPIを通じた公式ルートで取得します。
  • ✓
    アカウント停止リスクなし — 不正アクセスや規約違反がないため、セラーアカウント・アソシエイトアカウントへの影響はありません。
  • ✓
    API キーは自前で取得 — Amazon アソシエイトアカウント（無料）があれば PA-API キーを取得できます。取得手順もサポートします。
  • !
    取得できない項目もあります — PA-API の仕様上、一部の詳細バリエーション情報・重量などは取得できない場合があります。取得可能範囲を事前にお伝えします。
