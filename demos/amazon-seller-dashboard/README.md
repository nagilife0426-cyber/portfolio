# Amazon セラーレポート 集計ツール

AmazonセラーセントラルのCSV/Excelレポートを自動集計し、Googleスプレッドシート上にダッシュボードを生成するツールです。
Excel VBA版とGoogle Apps Script (GAS) 版の両方を同梱しています。

---

## 概要

| 項目 | 内容 |
|------|------|
| 対応レポート | 売上レポート / スポンサープロダクト広告レポート / FBA在庫レポート |
| 集計指標 | 純売上・粗利・粗利率・ACoS・在庫回転・在庫切れ予測日数 など |
| 実装 | GAS版（メイン）＋ Excel VBA版（サブ） |
| デモ | `demo.html` をブラウザで開くと集計結果を確認できます |

## 対応するAmazonレポート種別

### 1. 売上レポート（売上・注文ベース）
セラーセントラル → 「レポート」→「ビジネスレポート」→「注文別売上レポート」からダウンロードするCSV。

**主要列**:
- 注文日 / ASIN / SKU / 商品名 / 数量 / 売上高
- Amazon手数料 / FBA配送料 / FBA保管料
- 原価（セラー側で入力済みの場合）/ 返品数・返品額

### 2. 広告レポート（スポンサープロダクト）
セラーセントラル → 「広告」→「キャンペーンマネージャー」→「レポート」からダウンロードするCSV。

**主要列**:
- キャンペーン名 / 広告グループ名 / ASIN / SKU
- インプレッション数 / クリック数 / 広告費 / 広告売上 / ACoS / ROAS

### 3. FBA在庫レポート
セラーセントラル → 「在庫」→「FBAダッシュボード」→「在庫レポート」からダウンロードするCSV。

**主要列**:
- ASIN / SKU / FBA在庫数 / 出荷可能在庫 / 平均販売速度/日 / 推定在庫切れ日数

## 列マッピングの考え方

Amazonのレポートはダウンロード設定・期間・アカウント設定によってヘッダー名が揺れることがあります。  
本ツールでは **「候補名リスト」方式** で表記ゆれに対応しています。

```javascript
// 例: 売上高列の認識候補
revenue: ['売上高', '売上', 'item-price', 'revenue', '商品価格', '商品代金']
```

認識できない列名がある場合は、`Importer.gs` の `SALES_COLUMN_MAP` / `AD_COLUMN_MAP` / `INVENTORY_COLUMN_MAP` に候補を追加してください。  
また、GASのカスタムメニュー「⚙️ 設定」→「列マッピング設定シートを表示」で現在の対応状況を確認できます。

## 集計ロジック

### 粗利の計算式

```
粗利 = 純売上 - 原価 - Amazon手数料 - FBA配送料 - FBA保管料 - 広告費
純売上 = 売上高 - 返品額
```

### ACoS (Advertising Cost of Sale)

```
ACoS (%) = 広告費 / 広告売上 × 100
```

ACoSが低いほど広告効率が良いことを示します。一般的には20〜30%以下が目安です。

### ROAS (Return on Advertising Spend)

```
ROAS = 広告売上 / 広告費
```

### 在庫切れ予測日数

```
推定在庫切れまでの日数 = FBA在庫数 ÷ 平均販売速度（個/日）
```

## GAS版 導入手順

### 1. スプレッドシートの準備

1. 新しいGoogleスプレッドシートを作成する
2. メニュー「拡張機能」→「Apps Script」を開く

### 2. スクリプトのインポート

1. Apps Scriptエディタで新しいファイルを作成（.gsファイルを1つずつ）
2. 以下のファイルを追加する:
   - `Importer.gs`
   - `Aggregator.gs`
   - `Dashboard.gs`
   - `Menu.gs`
3. 各ファイルの内容をコピー＆ペーストする
4. 保存（Ctrl+S）

### 3. 権限の付与

スクリプト初回実行時に以下の権限許可が必要です:
- Googleスプレッドシートの読み書き
- Googleドライブのファイル読み取り（CSVのアップロードと読み込みに使用）

### 4. 使い方（ワンクリック実行）

スプレッドシートをリロードすると「🛒 Amazon集計ツール」メニューが追加されます。

```
1. [📥 1. レポート取込] → 売上/広告/在庫のCSVをGoogleドライブにアップロードし、ファイルIDを入力
2. [📊 2. 集計を実行] → SUMMARY シートが生成されます
3. [📈 3. ダッシュボードを更新] → DASHBOARD シートにKPI・グラフ・テーブルが生成されます
```

または「⚡ 全処理を一括実行」でまとめて実行できます。

## VBA版 導入手順

### 1. モジュールのインポート

1. Excelでワークブックを開く（`.xlsm` 形式で保存推奨）
2. `Alt + F11` でVBAエディタを開く
3. 「ファイル」→「ファイルのインポート」で `vba/Module1.bas` を選択する

### 2. 使い方

VBAエディタの「マクロ」一覧から以下のマクロを実行してください:

| マクロ名 | 機能 |
|---------|------|
| `ImportSalesReport` | 売上レポートCSVを取込 |
| `ImportAdReport` | 広告レポートCSVを取込 |
| `ImportInventoryReport` | 在庫レポートCSVを取込 |
| `RunAggregation` | 集計を実行してSUMMARYシートを更新 |
| `BuildDashboard` | ダッシュボードシートを生成 |
| `RunAll` | 集計からダッシュボード生成まで一括実行 |

## 生成されるシート一覧

| シート名 | 内容 |
|---------|------|
| `RAW_売上` | 取り込んだ売上レポート（標準フォーマット変換済み） |
| `RAW_広告` | 取り込んだ広告レポート |
| `RAW_在庫` | 取り込んだ在庫レポート |
| `SUMMARY` | 月別・商品別の集計結果テーブル |
| `DASHBOARD` | KPIカード・月別推移グラフ・在庫アラート |
| `MAPPING_CONFIG` | 列マッピング設定の参照シート |

## 制限事項

- 本ツールで使用するサンプルデータはすべてダミーです。実在する商品・企業・データとは無関係です。
- GAS版は月の実行時間上限（6分/回）があります。10,000行を超える大量データの場合は分割実行が必要です。
- VBA版はExcel 2016以降 (Microsoft 365推奨) が必要です。
- 外部APIへの送信は行いません。すべての処理はスプレッドシート/ブック内で完結します。
- AmazonのレポートCSV仕様はアカウント設定・セラーセントラルのバージョンによって変動する場合があります。列名が認識されない場合は `Importer.gs` のマッピング定義を修正してください。
