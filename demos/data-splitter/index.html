📋 制作仕様・自動化の仕組み

「縦に貼り付けた複数行を横1行に自動仕分けする」ツールの仕組み・揺れ吸収の方針・実装フローをご説明します。

1. 何をどう自動化するか（平易な言葉で）
  1. 1
    メモや管理システムから縦ブロックをそのままコピーする
    名前・好きな食べ物・好きなアーティスト・おすすめのドラマ…といった回答がメモアプリに1項目=1行で縦並びになっています。それをそのまま全選択コピーします。
  2. 2
    スプレッドシートの A 列に1回貼り付けるだけ
    A2 セルに貼り付けると、スプレッドシートは縦4行（A2〜A5）にデータを配置します。これが「1人分が縦に広がった状態」です。
  3. 3
    GAS が自動検知して横1行（A2 / B2 / C2 / D2）に転置する
    onEdit トリガーが A 列への2行以上の貼り付けを検知。縦に並んだ値を横1行に並べ替え（転置）し、A2 に全データを横展開します。1行目のヘッダー（名前 / 好きな食べ物…）に合わせて自動配置。
  4. 4
    5人分は人ごとに次の行へ繰り返すだけ
    2人目は A3 に貼り付ければ B3・C3・D3 に自動展開。5人分を繰り返せば5行の表が完成します。空行で区切った一括貼り付けには GAS のカスタムメニュー版が対応します。
2. 揺れ吸収の方針（3 パターン）
✂️
前後の余白
各行を個別 trim
各行の先頭・末尾のスペース・タブを除去してからセルへ書き込み。コピー元のインデントや末尾スペースが残っていても正しく配置されます。
⬜
空行の混入
自動スキップ
メモの先頭・末尾・途中に空行が入っていても無視します。trim 後が空文字の行はフィールドとしてカウントしないため、列がズレません。
📐
項目数の過不足
安全な長さ合わせ
人によって記入項目数が違っても崩れません。項目が少ない場合は末尾セルを空欄のまま保持、多い場合は右方向へ追加で展開します。

Google Apps Script — onEdit 自動実行版 
/**
 * 縦に貼り付けた複数行を、自動で横1行に並べ替える
 * 使い方: A列の空いている行に、メモからコピーした複数行をそのまま貼り付けるだけ。
 *         例) 名前 / 好きな食べ物 / 好きなアーティスト / おすすめのドラマ の4行
 *         → 貼り付けた行の A・B・C・D… に横並びで自動配置。5名ぶん繰り返せます。
 */
function onEdit(e) {
  if (!e || !e.range) return;
  var range = e.range;
  if (range.getColumn() !== 1 || range.getNumColumns() !== 1 || range.getNumRows() < 2) return;
  var topRow = range.getRow();
  var values = range.getValues()
    .map(function (r) { return (r[0] === null ? '' : String(r[0]).trim()); })
    .filter(function (v) { return v !== ''; });
  if (values.length < 2) return;
  var sheet = range.getSheet();
  sheet.getRange(topRow, 1, range.getNumRows(), 1).clearContent();
  sheet.getRange(topRow, 1, 1, values.length).setValues([values]);
}
Google Apps Script — カスタムメニュー版（複数人まとめて処理） 
/**
 * カスタムメニュー版: A列の縦ブロックを横1行に転置（複数人まとめて処理）
 * 使い方: A列に複数人分のデータを縦に貼り付けた後、
 *         「データ整形」メニュー →「縦→横に転置」を実行する。
 *
 * 前提: 人と人の間は空行1行で区切る。1行目はヘッダー行。
 * 例:
 *   A2: テスト花子     → A2=テスト花子 / B2=りんご / C2=Michael Jackson / D2=愛の不時着
 *   A3: りんご
 *   A4: Michael Jackson
 *   A5: 愛の不時着
 *   A6: （空行）
 *   A7: 鈴木次郎       → A3=鈴木次郎 / B3=ラーメン / ...
 *   ...
 */

// ===== 設定（ここだけ変えれば動く） =====
var CONF = {
  SHEET_NAME:  'Sheet1',  // 対象シート名
  SOURCE_COL:  1,         // 貼り付け列（1=A列）
  HEADER_ROW:  1,         // ヘッダー行番号（スキップ）
  DATA_START:  2,         // データ開始行（2=A2）
  HEADERS: ['名前', '好きな食べ物', '好きなアーティスト', 'おすすめのドラマ']
           // ↑ 実際の項目名に合わせて変更する
};

// ===== メニュー追加 =====
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('データ整形')
    .addItem('縦→横に転置する', 'transposeAll')
    .addItem('ヘッダーを設定する', 'setupHeaders')
    .addToUi();
}

// ===== ヘッダー設定 =====
function setupHeaders() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONF.SHEET_NAME);
  if (!sheet) return;
  CONF.HEADERS.forEach(function(name, i) {
    sheet.getRange(CONF.HEADER_ROW, CONF.SOURCE_COL + i).setValue(name);
  });
}

// ===== メイン: A列の縦ブロックを横1行に転置 =====
function transposeAll() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONF.SHEET_NAME);
  if (!sheet) {
    SpreadsheetApp.getUi().alert('シートが見つかりません: ' + CONF.SHEET_NAME);
    return;
  }
  var lastRow = sheet.getLastRow();
  if (lastRow < CONF.DATA_START) return;

  // A列のデータを一括取得
  var srcValues = sheet
    .getRange(CONF.DATA_START, CONF.SOURCE_COL, lastRow - CONF.DATA_START + 1, 1)
    .getValues();

  // 空行で区切ってブロックに分割
  var blocks = [];
  var current = [];
  srcValues.forEach(function(row) {
    var v = (row[0] === null ? '' : String(row[0]).trim());
    if (v === '') {
      if (current.length > 0) { blocks.push(current); current = []; }
    } else {
      current.push(v);
    }
  });
  if (current.length > 0) blocks.push(current);
  if (blocks.length === 0) return;

  // 最大列数を計算
  var maxCols = blocks.reduce(function(m, b) { return Math.max(m, b.length); }, 0);

  // 各ブロックを横1行に（列数を揃えてパディング）
  var output = blocks.map(function(b) {
    var row = b.slice();
    while (row.length < maxCols) row.push('');
    return row;
  });

  // A列のデータを消してから横書き（DATA_START行目から）
  sheet.getRange(CONF.DATA_START, CONF.SOURCE_COL, lastRow - CONF.DATA_START + 1, 1)
    .clearContent();
  sheet.getRange(CONF.DATA_START, CONF.SOURCE_COL, output.length, maxCols)
    .setValues(output);

  SpreadsheetApp.getUi().alert(output.length + ' 件を横1行に転置しました。');
}
Excel VBA（おまけ：縦選択 → 横1行に転置） 
' =====================================================
' 縦転置マクロ（Excel VBA版）
' A列の縦ブロックを読み取り、横1行に転置して出力する
' 使い方: A列に縦ブロックを貼り付けた後、このマクロを実行する。
'         空行区切りで複数人分をまとめて処理できる。
' =====================================================

Sub TransposeToCols()

    Const SOURCE_COL  As Long = 1   ' A列
    Const HEADER_ROW  As Long = 1   ' ヘッダー行（スキップ）
    Const DATA_START  As Long = 2   ' データ開始行

    Dim ws       As Worksheet
    Dim lastRow  As Long
    Dim r        As Long
    Dim outRow   As Long
    Dim col      As Long
    Dim v        As String
    Dim block()  As String
    Dim cnt      As Long

    Set ws = ActiveSheet
    lastRow = ws.Cells(ws.Rows.Count, SOURCE_COL).End(xlUp).Row
    If lastRow < DATA_START Then Exit Sub

    Application.ScreenUpdating = False

    outRow = DATA_START
    cnt = 0
    ReDim block(0)

    For r = DATA_START To lastRow + 1  ' +1 で末尾ブロックを確実に処理

        If r <= lastRow Then
            v = Trim(ws.Cells(r, SOURCE_COL).Value)
        Else
            v = ""  ' 末尾フラッシュ用
        End If

        If v = "" Then
            ' 空行 or 終端 → ブロックを横1行に書き出す
            If cnt > 0 Then
                For col = 0 To cnt - 1
                    ws.Cells(outRow, SOURCE_COL + col).Value = block(col)
                Next col
                outRow = outRow + 1
                cnt = 0
                ReDim block(0)
            End If
        Else
            ' 値あり → ブロックに追記
            ReDim Preserve block(cnt)
            block(cnt) = v
            cnt = cnt + 1
        End If

    Next r

    ' 元の縦データ（outRow以降）が残っていれば消去
    If outRow <= lastRow Then
        ws.Range(ws.Cells(outRow, SOURCE_COL), ws.Cells(lastRow, SOURCE_COL)).ClearContents
    End If

    Application.ScreenUpdating = True
    MsgBox (outRow - DATA_START) & " 件を横1行に転置しました。", vbInformation

End Sub
