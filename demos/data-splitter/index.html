セル貼り付け → 複数列に自動分割

システムからコピーした情報を 1 セルに貼り付けるだけで、
A・B・C…列へ自動的に振り分ける GAS ツール

📌 GAS スプレッドシート優先
🔄 区切り 自動判定 or 手動選択
🧹 揺れ吸収 全角/半角・連続空白・前後trim
⚡ VBA Excel版コードも同梱
インタラクティブ・デモ（ブラウザで動きます）
📥 入力：システムからコピーした貼り付け文字列（1行 = 1レコード）
揺れ吸収の例（含まれていても正しく分割）
全角スペース「　」 連続スペース「 」 タブ混在 前後の空白 項目数の過不足
📊 分割結果（スプレッドシートに貼れるTSVでコピーできます）
⚠️ これはブラウザ上で動くデモです。データはサーバーへ送信されません。実際の GAS は Google スプレッドシートに組み込んで使います。
📋 制作仕様・自動化の仕組み

「1セルに貼り付けた情報を複数列へ自動分割する」ツールの仕組み・揺れ吸収の方針・実装フローをご説明します。

1. 何をどう自動化するか（平易な言葉で）
  1. 1
    システムからコピーして 1 つのセルに貼り付ける
    社内管理システムや外部ツールから情報をコピーすると、名前・食べ物・アーティスト名などが 1 つの文字列にまとまって貼り付けられることがあります。これがそのまま 1 セルに収まってしまう状態です。
  2. 2
    GAS が区切り文字を自動判定して各列に振り分ける
    貼り付けた瞬間（onEdit）またはボタン押下でスクリプトが起動。タブ → カンマ → 空白の優先順でどの区切りかを自動判定し、A列の文字列を B・C・D…列へ自動展開します。
  3. 3
    揺れを吸収してきれいに揃える
    全角スペースを半角に変換、連続するスペース/タブを 1 つに圧縮、前後の余分な空白をトリム。項目数が行によって異なってもエラーにならず、足りない列は空欄のまま保持します。
  4. 4
    A 列の元データは残す or 消すを設定で切り替え
    分割後に A 列の元テキストを消すかどうかをコード内の定数 CLEAR_SOURCE で制御できます。メンテが容易なシンプルな構成です。
2. 揺れ吸収の方針（4 パターン）
⬛
全角 / 半角スペース
統一変換
全角スペース「　」を半角スペース「 」に置換。IME 切り替えミスや、コピー元の文字コード差異によるスペース混在を自動解消します。
🔤
連続空白 / タブ
圧縮（collapseWhitespace）
「スペース 3 つ続き」「スペース＋タブ混在」を正規表現 /[\s　]+/g で 1 つに圧縮。見えない文字による列ズレを防ぎます。
✂️
前後の余白
trim（各セル単位）
分割後の各項目に個別に trim を適用。行頭・行末だけでなく、分割後の各フィールドの先頭・末尾スペースも除去するため、セル内に空白が残りません。
📐
項目数の過不足
安全な長さ合わせ
分割結果が最大列数より少ない行は末尾に空文字を補完。多い行はそのまま末尾に追加。どちらも崩れず、既存データを上書きしません。

Google Apps Script 
// =====================================================
// データ分割ツール（カスタムメニュー実行版）
// スプレッドシートに貼り付けて「データ分割」メニューから実行
// =====================================================

// ===== 設定（ここだけ変えれば動く） =====
const CONFIG = {
  SHEET_NAME:   'Sheet1',       // 対象シート名
  SOURCE_COL:   1,              // 貼り付け列（1=A列）
  TARGET_START: 2,              // 分割先の開始列（2=B列）
  MAX_COLS:     18,             // 分割先の最大列数（A〜R列）
  HEADER_ROW:   1,              // ヘッダー行番号（1=1行目）
  DATA_START:   2,              // データ開始行（2=2行目）
  CLEAR_SOURCE: false,          // 分割後にA列の元テキストを消すか
  HEADERS: [                      // ヘッダー名（実データに合わせて変更）
    '名前', '好きな食べもの', '好きなアーティスト',
    'おすすめドラマ', '出身地', '趣味',
    '好きな映画', '好きな季節', '将来の夢', '座右の銘'
  ]
};

// ===== メニュー追加 =====
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('データ分割')
    .addItem('選択列を分割する', 'splitData')
    .addItem('ヘッダーを設定する', 'setupHeaders')
    .addToUi();
}

// ===== ヘッダー自動設定 =====
function setupHeaders() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName(CONFIG.SHEET_NAME);
  if (!sheet) return;

  // A列ヘッダー
  sheet.getRange(CONFIG.HEADER_ROW, CONFIG.SOURCE_COL)
    .setValue('貼り付けデータ（元）');

  // B列以降のヘッダー
  CONFIG.HEADERS.forEach(function(name, i) {
    sheet.getRange(CONFIG.HEADER_ROW, CONFIG.TARGET_START + i)
      .setValue(name);
  });
}

// ===== メイン：データ分割処理 =====
function splitData() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName(CONFIG.SHEET_NAME);
  if (!sheet) {
    SpreadsheetApp.getUi().alert('シートが見つかりません: ' + CONFIG.SHEET_NAME);
    return;
  }

  const lastRow = sheet.getLastRow();
  if (lastRow < CONFIG.DATA_START) return; // データなし

  // A列のデータ行を一括取得
  const srcRange = sheet.getRange(CONFIG.DATA_START, CONFIG.SOURCE_COL,
    lastRow - CONFIG.DATA_START + 1, 1);
  const srcValues = srcRange.getValues();

  // 分割結果を配列に格納
  const output = srcValues.map(function(row) {
    const raw = String(row[0]);
    if (!raw.trim()) return Array(CONFIG.MAX_COLS).fill('');
    return parseFields(raw, CONFIG.MAX_COLS);
  });

  // B列以降に一括書き込み（高速）
  sheet.getRange(CONFIG.DATA_START, CONFIG.TARGET_START,
    output.length, CONFIG.MAX_COLS)
    .setValues(output);

  // A列の元データを消すオプション
  if (CONFIG.CLEAR_SOURCE) {
    srcRange.clearContent();
  }

  SpreadsheetApp.getUi().alert(output.length + ' 行を分割しました。');
}

// ===== 区切り自動判定 + 揺れ吸収 =====
function parseFields(raw, maxCols) {
  // 1. 全角スペースを半角に統一
  let text = raw.replace(/　/g, ' ');

  // 2. 区切り文字を自動判定（タブ → カンマ → 空白の優先）
  let parts;
  if (text.indexOf('\t') !== -1) {
    // タブ区切り: 各フィールドをtrimするだけ（連続タブは空フィールド扱い）
    parts = text.split('\t').map(function(s) { return s.trim(); });
  } else if (text.indexOf(',') !== -1) {
    // カンマ区切り
    parts = text.split(',').map(function(s) { return s.trim(); });
  } else {
    // スペース区切り: 連続スペースを1つに圧縮してから分割
    parts = text.trim().replace(/\s+/g, ' ').split(' ');
  }

  // 3. 最大列数に合わせてパディング or トリム
  const result = [];
  for (let i = 0; i < maxCols; i++) {
    result.push(i < parts.length ? parts[i] : '');
  }
  return result;
}
Google Apps Script — onEdit 自動実行版 
// =====================================================
// データ分割ツール（onEdit 自動実行版）
// A列に貼り付けた瞬間に自動でB列以降へ展開する
// =====================================================

// ===== 設定 =====
const SPLIT_CONFIG = {
  SHEET_NAME:   'Sheet1',
  SOURCE_COL:   1,              // 1=A列
  TARGET_START: 2,              // 2=B列
  MAX_COLS:     18,             // A〜R列（A除く最大18）
  HEADER_ROW:   1,              // この行は処理スキップ
  CLEAR_SOURCE: false
};

// ===== onEdit トリガー =====
function onEdit(e) {
  const range = e.range;
  const sheet = range.getSheet();

  // 対象シートかチェック
  if (sheet.getName() !== SPLIT_CONFIG.SHEET_NAME) return;

  // A列（SOURCE_COL）かチェック
  if (range.getColumn() !== SPLIT_CONFIG.SOURCE_COL) return;

  // ヘッダー行はスキップ
  const startRow = range.getRow();
  if (startRow <= SPLIT_CONFIG.HEADER_ROW) return;

  // 編集された A 列の行を全部処理
  const numRows = range.getNumRows();
  const srcValues = sheet
    .getRange(startRow, SPLIT_CONFIG.SOURCE_COL, numRows, 1)
    .getValues();

  const output = srcValues.map(function(row) {
    const raw = String(row[0]);
    if (!raw.trim()) return Array(SPLIT_CONFIG.MAX_COLS).fill('');
    return parseFieldsEdit(raw, SPLIT_CONFIG.MAX_COLS);
  });

  // B列以降に書き込み
  sheet.getRange(startRow, SPLIT_CONFIG.TARGET_START, numRows, SPLIT_CONFIG.MAX_COLS)
    .setValues(output);

  if (SPLIT_CONFIG.CLEAR_SOURCE) {
    sheet.getRange(startRow, SPLIT_CONFIG.SOURCE_COL, numRows, 1).clearContent();
  }
}

// ===== 区切り自動判定 + 揺れ吸収 =====
function parseFieldsEdit(raw, maxCols) {
  let text = raw.replace(/　/g, ' '); // 全角スペース→半角

  let parts;
  if (text.indexOf('\t') !== -1) {
    parts = text.split('\t').map(function(s) { return s.trim(); });
  } else if (text.indexOf(',') !== -1) {
    parts = text.split(',').map(function(s) { return s.trim(); });
  } else {
    parts = text.trim().replace(/\s+/g, ' ').split(' ');
  }

  const result = [];
  for (let i = 0; i < maxCols; i++) {
    result.push(i < parts.length ? parts[i] : '');
  }
  return result;
}
Excel VBA（おまけ：同等処理の簡潔版） 
' =====================================================
' データ分割マクロ（Excel VBA版）
' A列のデータをB列以降に自動分割する
' =====================================================

Sub SplitCellData()

    Const SOURCE_COL   As Long = 1   ' A列
    Const TARGET_START As Long = 2   ' B列から出力
    Const MAX_COLS     As Long = 18  ' 最大分割列数
    Const HEADER_ROW   As Long = 1   ' ヘッダー行（スキップ）
    Const CLEAR_SOURCE As Boolean = False

    Dim ws      As Worksheet
    Dim lastRow As Long
    Dim r       As Long
    Dim raw     As String
    Dim parts() As String
    Dim i       As Long

    Set ws = ActiveSheet
    lastRow = ws.Cells(ws.Rows.Count, SOURCE_COL).End(xlUp).Row

    Application.ScreenUpdating = False

    For r = HEADER_ROW + 1 To lastRow

        raw = ws.Cells(r, SOURCE_COL).Value

        ' 空行はスキップ
        If Trim(raw) = "" Then GoTo NextRow

        ' 全角スペースを半角に変換
        raw = Replace(raw, Chr(12288), " ")

        ' 区切り判定（タブ → カンマ → スペース）
        If InStr(raw, vbTab) > 0 Then
            parts = Split(raw, vbTab)
        ElseIf InStr(raw, ",") > 0 Then
            parts = Split(raw, ",")
        Else
            ' 連続スペースを1つに圧縮（簡易版）
            Do While InStr(raw, "  ") > 0
                raw = Replace(raw, "  ", " ")
            Loop
            parts = Split(Trim(raw), " ")
        End If

        ' B列以降に書き込み（MAX_COLS 分）
        For i = 0 To MAX_COLS - 1
            If i <= UBound(parts) Then
                ws.Cells(r, TARGET_START + i).Value = Trim(parts(i))
            Else
                ws.Cells(r, TARGET_START + i).Value = ""
            End If
        Next i

        If CLEAR_SOURCE Then
            ws.Cells(r, SOURCE_COL).Value = ""
        End If

NextRow:
    Next r

    Application.ScreenUpdating = True
    MsgBox "分割完了しました。", vbInformation

End Sub
