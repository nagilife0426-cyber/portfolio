スプシ1行 → モール別 出品文ジェネレーター

スプレッドシートの商品1行から、楽天・Amazon・Yahoo!ショッピング向けに最適化した「タイトル / 商品説明 / 検索キーワード」を出し分けます。各モールの文字数上限・説明文の形式（HTML可否）・禁止表現を踏まえて自動整形。
⚠ これはサンプル出力デモです（APIキー不使用）。本番はClaude APIが御社スプシから各モールのトーンで自動生成します。

📄 商品データ（スプシ1行・編集可）

🛒 生成結果

タイトル目安255字・説明HTML可
Amazon
タイトル目安200字・型番必須
Yahoo!ショッピング
タイトル目安75字・前寄せ
左で「⚡ 3モール分を生成」を押すと、ここに出し分け結果が表示されます。

本番の仕組み（このデモの先）

スプレッドシート（商品マスタ）→ Claude API でモール別に文章生成→ 禁止語フィルタ＋文字数最適化→ 出品用CSV / 各モールAPIへ書き出し
※ GAS（スプレッドシート連携）またはPythonで構築。Amazonは SP-API、楽天は RMS、Yahoo!ショッピングは各連携 or CSV一括登録に対応。出品文は人の最終確認を挟むドラフト生成として組みます。
