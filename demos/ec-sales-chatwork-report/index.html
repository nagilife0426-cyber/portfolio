    2. 使用技術スタック
    🛍️
    各モール API
    売上データ取得元
    Amazon SP-API・楽天 RMS API・TikTok Shop API から前日分を自動取得。API 申請前はセラーセントラルの CSVレポートを自動読込で先行稼働できます。
    📊
    Google Sheets / GAS
    集計・蓄積・定時実行
    集計エンジンは GAS スクリプトで実装。スプレッドシートに日次データを蓄積しトレンド確認が可能。GAS のタイムドリガーで毎朝 08:00 に自動起動します。
    🐍
    Python
    代替バックエンド
    GAS の代わりに Python（requests + pandas）でも実装可能。サーバー環境があれば cron で同様に定時実行できます。既存システムへの組み込みに最適です。
    💬
    Chatwork API
    通知・メッセージ送信
    Chatwork 公式 API（POST /v2/rooms/{ROOM_ID}/messages）を使用。ヘッダに X-ChatWorkToken を設定するだけで指定ルームへメッセージを投稿できます。無料プランで利用可。
    🔔
    GAS タイムドリガー / cron
    定時実行エンジン
    GAS 版は GUI でトリガー設定するだけでサーバー不要。Python 版は VPS や Cloud Run に cron を設定します。どちらも毎朝 08:00 に確実に実行されます。
    📈
    Chatwork 記法
    メッセージ整形
    [info][title]…[/title]…[/info] 記法を使い、タイトル付きのボックス形式で見やすいレポートを生成。前日比の ▲/▼ 自動付与で一目で数値変化がわかります。

    4. 処理フローの流れ（平易な日本語で）
    1. 1
      毎朝 08:00 に自動で起動
      GAS のタイムドリガーまたは cron が定刻に集計スクリプトを起動します。休日も祝日も関係なく毎日実行されます（停止したい日は設定で除外可）。
    2. 2
      各モールから前日分の売上データを自動取得
      Amazon SP-API・楽天 RMS API・TikTok Shop API から前日 00:00〜23:59 の売上・注文・広告データを自動で引っ張ってきます。API 申請前の期間はセラーセントラルの CSV を所定フォルダに置くだけで同じ処理が走ります。
    3. 3
      集計・加工（粗利/ACoS/前日比を自動計算）
      チャンネルごとに売上・手数料・広告費・仕入れ原価を集計し、粗利・粗利率・ACoS（広告費÷広告売上）・前日比を自動計算します。結果はスプレッドシートに蓄積されるため、週次・月次の振り返りも可能です。
    4. 4
      Chatwork 記法でメッセージを整形
      [info][title]…[/title]…[/info] 記法を使い、タイトル付きのボックス形式で見やすいレポート文を生成します。前日比の▲/▼も自動で付与されるので、増減が一目でわかります。
    5. 5
      Chatwork API で指定ルームへ自動投稿
      Chatwork API（POST /v2/rooms/{ROOM_ID}/messages）へリクエストを送信し、指定したルームへレポートが届きます。チームメンバーは朝出社したら Chatwork を開くだけで最新の売上状況がわかります。
    5. 運用イメージ（人がやることはゼロ）
    ☕
    人がやること
    毎朝 Chatwork を開くだけです。集計・計算・メッセージ送信はすべて自動。手でスプレッドシートを開いたり、数字をコピペする作業はゼロになります。
    🤖
    システムがやること
    データ取得・集計・粗利/ACoS/前日比の計算・メッセージ整形・Chatwork 送信・スプレッドシート蓄積をすべて自動実行します。
    🔔
    Slack / メールへの切替
    Chatwork を使わなくなっても、送信先を Slack（Incoming Webhook）やメール（GmailApp.sendEmail）に切り替えるだけで同じレポートが届きます。
    📐
    レポート内容の調整
    「在庫切れアラートも一緒に送りたい」「返品率を追加したい」など、項目の追加・削除はテンプレート関数を修正するだけで対応できます。
