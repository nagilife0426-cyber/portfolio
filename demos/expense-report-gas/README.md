# 出張報告書 自動生成システム — Googleフォーム × GAS

Googleフォームで出張情報を入力して送信するだけで、スプレッドシートに整形済みの報告書が自動生成されます。

---

## 概要

| 項目 | 内容 |
|------|------|
| 使用ツール | Googleフォーム、Google スプレッドシート、Google Apps Script |
| 費用 | 無料（Googleアカウントのみ） |
| 対象 | 非エンジニア・中小企業の総務・営業担当 |
| 導入工数 | 約1〜2時間（ヒアリング含む） |

---

## 仕組み

```
Googleフォーム
  ↓ 送信トリガー
GAS（onFormSubmit）
  ├─ 出張報告書シートに行を追記
  └─ 月次集計シートの合計を自動更新
```

---

## 導入手順

### 1. フォームを作成する

Googleフォームで以下の項目を作成します（質問タイトルは `Code.gs` の `FIELD` 定数と一致させてください）。

| 質問タイトル | 形式 | 必須 |
|------------|------|------|
| 氏名 | 短文 | ○ |
| 部署 | 短文 | ○ |
| 出張日 | 日付 | ○ |
| 帰着日 | 日付 | ○ |
| 目的地（会社名・場所） | 短文 | ○ |
| 出張目的 | 長文 | ○ |
| 交通費（円） | 短文（数字） | ○ |
| 宿泊費（円） | 短文（数字） | — |
| 日当（円） | 短文（数字） | — |
| その他経費（円） | 短文（数字） | — |
| 備考・特記事項 | 長文 | — |

> 項目を追加・削除する場合は `Code.gs` の `FIELD` 定数と `REPORT_HEADERS` 配列も合わせて修正してください。

### 2. スクリプトをコピーする

1. フォームの編集画面 → 右上メニュー（点3つ）→ 「スクリプトエディタ」を開く
2. `Code.gs` の内容をそのまま貼り付けて保存

### 3. トリガーを設定する

1. スクリプトエディタ → 「トリガー」アイコン（時計マーク）
2. 「トリガーを追加」→ 以下を設定
   - 実行する関数: `onFormSubmit`
   - イベントのソース: `フォームから`
   - イベントの種類: `フォーム送信時`
3. 権限の承認ダイアログが出たら許可する

### 4. シートを初期化する（任意）

スクリプトエディタで `initSheets` 関数を手動実行すると、ヘッダー付きのシートが自動作成されます。

### 5. 動作確認する

スクリプトエディタで `testOnFormSubmit` 関数を実行すると、ダミーデータで動作確認できます。

## カスタマイズ方法

### 項目を追加する

1. フォームに質問を追加
2. `Code.gs` の `FIELD` に `{ 新項目キー: '質問タイトル' }` を追記
3. `REPORT_HEADERS` の末尾に列名を追記
4. `appendReportRow` 内の `row` 配列に `data.新項目キー` を追記

### エラー通知先を変更する

`onFormSubmit` 内の `GmailApp.sendEmail(...)` の第1引数にメールアドレスを指定してください。

```javascript
GmailApp.sendEmail('your-email@example.com', '[要確認] ...', msg);
```
