フォーム → スプレッドシート自動仕分け

Googleフォームの送信内容をカテゴリ別シートに自動振り分け。対応漏れ・担当者混乱をなくします。

2 実際の GAS コード
JavaScript (Google Apps Script) — フォーム送信トリガー 
function onFormSubmit(e) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const responses = e.values;
  const category = responses[2]; // カテゴリ列

  const targetSheet = ss.getSheetByName(category)
    || ss.insertSheet(category);
  targetSheet.appendRow(responses);
}
3 このツールで解決できること
📤
対応漏れをゼロに
全件が1つのシートに混在していた状態から、カテゴリ別に整理。担当者がすぐ確認できます。
⚡
リアルタイム振り分け
フォーム送信と同時にトリガーが起動。手作業フィルタリングが完全に不要になります。
📈
カテゴリは自由に拡張
「問合せ/注文/クレーム」以外のカテゴリも、コード変更なしで自動的に新シートが作成されます。
🔔
通知連携も追加可能
クレーム受信時にSlack/Gmail通知を即時送信する処理も追加対応できます。
