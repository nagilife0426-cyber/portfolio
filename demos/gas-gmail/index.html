2 実際の GAS コード
JavaScript (Google Apps Script) 
function labelEmails(keyword, labelName) {
  const label = GmailApp.getUserLabelByName(labelName)
    || GmailApp.createLabel(labelName);

  const threads = GmailApp.search('subject:' + keyword + ' -label:' + labelName);
  threads.forEach(thread => {
    thread.addLabel(label);
  });

  return threads.length + '件にラベル「' + labelName + '」を付与しました';
}
3 このツールで解決できること
🔎
過去メールも一括対応
Gmailフィルタは「以降」しか適用されませんが、GASなら過去の全受信トレイを遡ってラベル付けできます。
🌟
重複付与なし
-label:ラベル名 をクエリに含めることで、既にラベル済みのスレッドを除外し、二重処理を防ぎます。
⏱
定期実行で自動化
GASのタイマートリガーを設定すれば、毎朝9時に自動実行してメールボックスを常に整理できます。
🔒
複数ルールに対応
「請求書→経理」「クレーム→要対応」など、複数のキーワード・ラベルペアを一括処理できます。
