2 実際の GAS コード
JavaScript (Google Apps Script) 
function mergeSheets() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheets = ['シートA', 'シートB', 'シートC'];
  const output = ss.getSheetByName('集計') || ss.insertSheet('集計');
  output.clearContents();

  let allData = [];
  sheets.forEach(name => {
    const sh = ss.getSheetByName(name);
    if (!sh) return;
    const data = sh.getDataRange().getValues();
    allData = allData.concat(data.slice(1)); // ヘッダー除く
  });

  output.getRange(1, 1, allData.length, allData[0].length).setValues(allData);
  SpreadsheetApp.getUi().alert('集計完了！' + allData.length + '件のデータを統合しました。');
}

🕐

シート数・行数に制限なし
3シートのサンプルですが、100シート・1万行規模でも同じコードで動作します。

カスタマイズで用途を拡張
集計後に並び替え・重複除去・グラフ自動生成なども追加対応可能です。
