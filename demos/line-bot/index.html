Bot 処理フロー
1. LINEメッセージ受信 → Webhook起動
2. GAS でテキスト解析（キーワード判定）
3. スプレッドシートからデータ取得
4. LINE Messaging API でリプライ送信
実装コード（GAS）
// LINE Messaging API Webhook（Google Apps Script）
function doPost(e) {
  const events = JSON.parse(e.postData.contents).events;

  events.forEach(event => {
    if (event.type !== 'message') return;

    const userMessage = event.message.text;
    let reply = '';

    if (userMessage.includes('売上')) {
      // スプレッドシートからリアルタイムデータ取得
      const ss = SpreadsheetApp.openById('YOUR_SHEET_ID');
      const sheet = ss.getSheetByName('売上');
      const today = sheet.getRange(2, 2).getValue();
      reply = `本日の売上: ¥${today.toLocaleString()}\n前日比: +6.2% ↑`;

    } else if (userMessage.includes('在庫')) {
      reply = checkInventory();  // 在庫シートを参照

    } else if (userMessage.includes('レポート')) {
      reply = generateReport();  // 月次集計を生成

    } else {
      reply = 'コマンド一覧:\n📊 売上\n📦 在庫\n📋 レポート';
    }

    replyToLine(event.replyToken, reply);
  });
}

function replyToLine(token, message) {
  UrlFetchApp.fetch('https://api.line.me/v2/bot/message/reply', {
    method: 'POST',
    contentType: 'application/json',
    headers: { 'Authorization': `Bearer ${LINE_CHANNEL_TOKEN}` },
    payload: JSON.stringify({
      replyToken: token,
      messages: [{ type: 'text', text: message }]
    })
  });
}

売上・在庫の即時確認

LINEを開くだけでリアルタイムのスプレッドシートデータを取得。外出中でも即確認。

アラート自動通知

在庫切れ・売上目標達成・値下がりをGASのトリガーで自動検知してLINE通知。

ノーサーバー運用

GAS（Google Apps Script）のみで動作。サーバー費用・インフラ管理は不要。
