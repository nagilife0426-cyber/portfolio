MEO運用代行 クライアント・セットアップ自動化（n8n）

新規クライアントの店舗情報をフォームに入れるだけで、Googleビジネスプロフィール運用の初期設定（口コミ返信テンプレ・投稿スケジュール・Slack承認フロー）を半自動で生成。1社あたりのセットアップ作業をゼロに近づけ、営業で取った店舗をそのまま運用に乗せます。

⚠ サンプル出力デモです（APIキー不使用・店舗データはダミー）。本番はn8nでGBP／Slack APIに接続します。

※ 実務では15〜25項目（営業時間・マップURL・画像URL等）に拡張。

n8nワークフロー（この自動化の全体像）

フォーム入力→ n8n Webhook受信→ 設定データ生成（Claudeで返信/投稿文）→ GBP接続・登録→ Slack承認→ 運用開始・ログ保存
※ クライアントごとに認証情報とデータを分離（n8nのクレデンシャル＋クライアントIDで名前空間を分け、他店舗に混ざらない設計）。
このデモについて（正直にお伝えします）
n8n・Webhook・Slack連携・Claudeでの文章生成は私の実領域です。Google Business Profile API の連携は本デモでは実装イメージ（ダミー出力）で、GBP案件そのものの納品実績はこれからです。GBPは公式コネクタ／APIの仕様が明確なので、テスト用プロフィールで先に通して確実に実装します。「できること」と「これからの部分」を分けてお伝えしたうえで、まず動くもので実力をご判断ください。
