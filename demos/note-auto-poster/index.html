    2. 使用技術スタック
    ⚙️
    n8n
    ワークフロー自動化エンジン
    毎週決まった曜日・時刻にトリガーを発火し、ネタ収集からパイプライン全体の起動を管制します。ノーコードでスケジュール変更が可能です。
    🤖
    Claude API（Sonnet）
    記事生成 AI
    ペルソナ・トーン・文字数・見出し構成を指定したプロンプトテンプレートで高品質な note 記事を生成。画像プロンプトの自動生成にも使用します。
    🐍
    Python
    バックエンド処理スクリプト
    スプレッドシートのデータ読み込み、Claude API 呼び出し、Markdown ファイル保存、画像 API 連携、Playwright の起動制御をすべて担います。
    🖼️
    画像生成 API
    サムネイル・図解の自動生成
    Kie.ai 等の API を使用してサムネイルと本文中の図解画像を自動生成。クライアントの要望に応じて API を選定します。
    🎭
    Playwright
    note ブラウザ自動操作
    note は公式投稿 API が非公開のため、ブラウザ自動操作で対応。ログイン状態保存・本文入力・画像挿入・スケジュール予約を自動化します。
    📊
    Google Sheets
    ネタ管理・ステータス管理
    収集したネタの一覧、チェックフラグ、生成ステータス、投稿日時のログをスプレッドシートで一元管理。人が確認・承認するためのインターフェースです。
    3. 処理フローの流れ（平易な日本語で）
    1. 1
      毎週自動でネタを集める
      n8n が毎週月曜朝 6 時に起動。X のトレンドワード・競合 note の人気記事・Googleトレンドを巡回し、「今週書くべきテーマ候補」をスプレッドシートに自動追記します。
    2. 2
      人がチェックを入れるだけ（唯一の手作業）
      スプレッドシートに並んだネタ一覧を見て、書きたいテーマの行にチェックを入れます。これが唯一の人間作業で、あとは完全自動です。
    3. 3
      Claude API（Sonnet）が記事を自動生成
      Python スクリプトがチェック済みのテーマを読み込み、事前に作成したプロンプトテンプレートで Claude Sonnet を呼び出します。ペルソナ・文字数・見出し構成・トーンを指定した高品質な記事が Markdown 形式で出力・保存されます。
    4. 4
      サムネイル・図解画像を AI が自動作成
      記事の内容を元に Claude が画像プロンプトを自動生成し、画像生成 API へ送信。サムネイルと本文中の図解画像が自動的に記事フォルダに保存されます。
    5. 5
      Playwright が note へ自動投稿・スケジュール予約
      Playwright が note のブラウザを自動操作。Markdown から本文を変換して入力し、生成済み画像を挿入、タグを設定、投稿スケジュールを予約します。複数記事を一括で予約投稿でき、週 1 回の作業（チェックを入れるだけ）で次の週の投稿がすべて埋まります。
    4. 運用イメージ（人がやることは 1 つだけ）
    ☑️
    人がやること
    週 1 回、スプレッドシートを開いてネタ候補にチェックを入れる。それだけです。記事生成・画像・投稿予約はすべて自動で完了します。
    🤖
    システムがやること
    ネタ収集・記事生成・画像生成・note 投稿予約のすべてを自動実行。生成された記事はスプレッドシートでステータス確認できます。
    ✏️
    記事の品質調整
    プロンプトテンプレートを変更するだけでトーン・文体・構成を一括変更できます。技術的な知識がなくても文章の方向性を指示できます。
    📈
    スケールアップ
    週 1 本から週 5 本への増量も設定変更のみ。複数のテーマカテゴリや複数アカウントへの展開も対応可能です。
