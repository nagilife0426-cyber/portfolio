実装コード（Python）

openpyxlでExcelを読み込み、smtplibでメール送信。crontabで毎週金曜17時に自動実行。

import datetime
from openpyxl import load_workbook
import smtplib
from email.mime.text import MIMEText

def generate_weekly_report():
    """毎週金曜17時に自動実行される週次レポート生成スクリプト"""
    wb = load_workbook('sales_data.xlsx')
    ws = wb.active

    # 今週のデータを取得
    today = datetime.date.today()
    week_start = today - datetime.timedelta(days=today.weekday())

    weekly_sales = []
    for row in ws.iter_rows(min_row=2, values_only=True):
        date, product, amount, rep = row
        if date and week_start <= date.date() <= today:
            weekly_sales.append({'date': date, 'amount': amount})

    # 集計
    total = sum(r['amount'] for r in weekly_sales)
    target = 1_000_000  # 週次目標
    achievement_rate = total / target * 100

    # レポート生成
    report = f"""
【週次レポート】{week_start} 〜 {today}

■ 売上サマリー
- 週間売上: ¥{total:,}
- 目標達成率: {achievement_rate:.1f}%
- 件数: {len(weekly_sales)}件
"""

    # メール送信
    send_report_email(report, recipients=['manager@company.com'])
    print(f"週次レポート送信完了: {datetime.datetime.now()}")

def send_report_email(content, recipients):
    msg = MIMEText(content, 'plain', 'utf-8')
    msg['Subject'] = f'【自動】週次レポート {datetime.date.today()}'
    msg['From'] = 'noreply@company.com'
    msg['To'] = ', '.join(recipients)

    with smtplib.SMTP('smtp.gmail.com', 587) as server:
        server.starttls()
        server.login('your_email@gmail.com', 'app_password')
        server.send_message(msg)

# schedule設定（crontab: 0 17 * * 5 python3 weekly_report.py）
if __name__ == '__main__':
    generate_weekly_report()

🔧 仕組み（How it works）

Excelデータから週報を自動生成し、メール送信するまでの技術と流れです。

📥
入力データ
売上・タスク・課題などのExcel/CSV
→
🐍
Python（集計・整形）
テンプレートに数値を差し込み週報を生成
→
📧
レポート出力・送信
本文を自動生成し、メールで自動送信
  • Python（pandas / openpyxl）でExcel・CSVを読み込み、売上やタスクの達成率を自動集計します。
  • 集計結果をレポートのテンプレートに差し込み、整った週報テキストを自動生成します。
  • 生成した本文はメールで自動送信（SMTP連携）。毎週金曜のまとめ・送信作業がゼロになります。
  • スケジュール実行で無人運用。集計項目やレポート文面は業務に合わせて自由に調整できます。
