    📋 制作仕様・自動化の仕組み

    このシステムがどう動くか、納品後の運用方法、制作の流れをご説明します。

    1. システム構成（3つの部品で動きます）
    📊
    Google
    スプレッドシート
    投稿（画像＋文章）の置き場。150パターンをここで管理
    →
    ⚙️
    GAS
    （自動実行プログラム）
    Google公式ツール。決めた時間に自動で動く「頭脳」部分
    →
    📸
    Instagram API
    （公式投稿窓口）
    Instagramの公式ルートで投稿を届ける。2アカウント対応
    →
    🧵
    Threads API
    （公式投稿窓口）
    Threadsの公式ルートで投稿を届ける。2アカウント対応
    2. 自動投稿の流れ（5ステップ）
    1. 1
      スプレッドシートに投稿を用意しておく
      画像のURL・本文テキストを行ごとに入力するだけ。Excelの表と同じ感覚で編集できます。
    2. 2
      GASが約30分ごと（ランダム間隔）に自動で起動
      人間が何も操作しなくても、設定した時間帯に自動で動き出します。「ランダム」にすることで、機械的な投稿に見えない自然なリズムを作ります。
    3. 3
      次の順番の投稿を4アカウントへ一斉送信
      Instagram 2アカウント＋Threads 2アカウントへ、公式のAPI（投稿窓口）を使って同時に届けます。
    4. 4
      「いつ・どれを投稿したか」をログに自動記録
      スプレッドシートに投稿日時を書き込み、同じ投稿を二重に出さない仕組みになっています。エラーがあれば理由も記録されます。
    5. 5
      150件すべて配信し終わったら1件目に戻って繰り返し
      ネタ切れなし。一度用意したコンテンツをずっと活用できます。
    3. 納品後はご自身で運用できます
    ✏️
    投稿の追加・修正
    スプレッドシートの行を足す・直すだけ。プログラムの知識は一切不要です。
    ⏰
    投稿間隔・時間帯の変更
    設定シートの数字を変えるだけ。「30分ごと→60分ごと」など、好みに合わせて調整できます。
    💰
    ランニングコスト
    GASは無料枠で完結します。Buffer・Makeのような月額サービス費用は不要です。
    4. 制作の進め方（3ステップ）
    1
    要件確認
    対象アカウント・投稿数・希望の投稿間隔をヒアリングします
    →
    2
    実装・接続
    スプレッドシート構築＋各SNSのAPI接続＋テスト投稿で動作確認
    →
    3
    納品
    GASコード一式＋スプレッドシート雛形＋操作マニュアル（図解付き）
