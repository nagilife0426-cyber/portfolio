# プロンプト設計書 - Threads 投稿文生成

## 概要

Claude API（claude-haiku-4-5）を使って、SNS集客向けのThreads投稿文を生成するためのプロンプト設計。

---

## システムプロンプト設計方針

### 役割定義
```
あなたはSNSマーケティングの専門家です。
Threadsに投稿する、読者を引きつける集客向け投稿文を生成します。
```

**意図:** 役割を明確にすることで、マーケティング文脈に即した文体・構成をモデルが選択しやすくなる。「SNS専門家」という役割付けにより、一般的な文章生成ではなくプラットフォーム特性を考慮した出力が得られる。

### ハード制約（守らせる）

| 制約項目 | 設定値 | 理由 |
|---------|--------|------|
| 文字数 | 500文字以内 | Threads APIの上限に合わせる |
| 出力形式 | 投稿本文のみ | 説明文や補足が混入しないようにする |
| ハッシュタグ | 末尾にまとめる | Threads の慣習・視認性向上 |

### ソフト制約（品質向上）

- 改行を適度に使い読みやすくする → スマートフォンでの視認性
- 絵文字を効果的に使う → エンゲージメント率向上
- 広告感を出しすぎない → Threadsユーザーは宣伝投稿を嫌う傾向

---

## ユーザープロンプト変数

ユーザープロンプトは以下の4変数で構成される。クライアント要件に合わせて変更可能。

```
テーマ: {theme}
トーン: {tone}
ターゲット: {target}
ハッシュタグ方針: {hashtag_policy}
追加指示: {extra_instruction}  ← 任意
```

### 各変数の設計意図

#### `theme`（投稿テーマ）
投稿の核となるトピック。具体的であるほど品質が高まる。

例:
- `副業の始め方` → 汎用的な入門系コンテンツ
- `副業月5万達成の3ステップ` → 数字・ステップ入りで具体性UP
- `AI活用で残業を週10時間削減した方法` → 体験談形式でリアリティ重視

#### `tone`（文体・トーン）
ブランドボイスに合わせて調整。

| トーン設定 | 向いている業種・用途 |
|-----------|---------------------|
| 親しみやすく・カジュアル | 個人事業主、コーチング、副業系 |
| 落ち着いた・知的 | コンサルタント、BtoB、士業 |
| 元気・背中を押す | フィットネス、モチベーション系 |
| 共感・体験談風 | 転職、育児、ライフスタイル |
| 教育系・わかりやすく | ハウツー、スキルシェア |

#### `target`（ターゲット読者）
ペルソナを具体的に書くほど、読者に刺さる文章になる。

例:
- NG: `会社員`（抽象的すぎる）
- OK: `副業に興味があるが何から始めればいいか分からない30代の会社員`

#### `hashtag_policy`（ハッシュタグ方針）
Threadsでのハッシュタグ戦略。

| 方針 | 件数 | 用途 |
|------|------|------|
| ビッグキーワード中心 | 3〜5個 | 拡散重視 |
| ニッチキーワード中心 | 5〜8個 | ターゲット層への精度重視 |
| ブランドタグ含む | 3〜5個 | ブランド認知重視 |

## 品質ガードの設計

### 1. 文字数チェック
```python
if len(text) > 500:
    FAIL
```
Threads API の上限（500文字）を超えると投稿自体が失敗する。最初に確認。

### 2. NGワードチェック
景品表示法・特定商取引法に抵触するリスクのある表現を除外。

```python
NG_WORDS = ["絶対", "確実に儲かる", "必ず稼げる", ...]
```

**カスタマイズポイント:** クライアントの業種・地域ルールに合わせてリストを拡張可能。

### 3. 重複チェック
SHA-256 ハッシュの先頭16文字で過去生成との照合。

```python
hash = sha256(text).hexdigest()[:16]
```

同一内容の繰り返し投稿を防ぎ、アカウントの信頼性を保つ。

## リトライ設計

品質チェック失敗時は最大2回自動リトライ。
温度パラメータはHaikuのデフォルト（変更なし）を使用し、リトライごとに自然なバリエーションが生成される。
