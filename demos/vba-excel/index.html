Excel 自動レポート生成マクロ

売上データシートから月次レポートを1クリックで自動生成します。集計・グラフ作成・書式設定まですべて自動化。

インタラクティブデモ
📊 月次売上管理.xlsm — Excel
売上データ
月次レポート
A B C D
「レポート生成」ボタンを押すと、ここに月次レポートが表示されます
実装コード（VBA）
Sub GenerateMonthlyReport()
    Dim ws As Worksheet
    Dim reportSheet As Worksheet

    Set ws = ThisWorkbook.Sheets("売上データ")

    ' レポートシートを作成（既存なら削除して再作成）
    On Error Resume Next
    Application.DisplayAlerts = False
    ThisWorkbook.Sheets("月次レポート").Delete
    Application.DisplayAlerts = True
    On Error GoTo 0

    Set reportSheet = ThisWorkbook.Sheets.Add(After:=ws)
    reportSheet.Name = "月次レポート"

    ' ヘッダー・集計値を設定
    With reportSheet
        .Cells(1, 1).Value = "月次売上レポート"
        .Cells(1, 1).Font.Size = 16
        .Cells(1, 1).Font.Bold = True

        Dim lastRow As Long
        lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row

        .Cells(3, 1).Value = "合計売上"
        .Cells(3, 2).Value = Application.WorksheetFunction. _
            Sum(ws.Range("C2:C" & lastRow))

        .Cells(4, 1).Value = "平均売上"
        .Cells(4, 2).Value = Application.WorksheetFunction. _
            Average(ws.Range("C2:C" & lastRow))
    End With

    MsgBox "月次レポートを生成しました！"
End Sub
解決できること
📋

月次レポート自動化

毎月のコピペ作業をボタン1つに。集計ミスを完全に排除し、報告書作成を数分で完了。

📊

グラフ自動生成

データ更新のたびに棒グラフ・折れ線グラフを自動再描画。フォーマット設定も自動適用。

📧

メール自動送信

Outlook連携でレポート完成後に担当者へ自動メール。添付ファイル名も自動命名。

🔗

複数シート・ファイル連携

複数部署のExcelを統合集計。フォルダ内の全ファイルを順次処理するバッチ処理も可能。
