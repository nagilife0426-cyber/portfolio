経費精算書 自動生成マクロ

❌ 課題: 経費精算書をExcelで手入力して、合計や税額を電卓で計算している

✅ 解決: VBAマクロでフォーム入力 → 帳票を一発生成・印刷まで自動化

📝 経費入力フォーム VBAマクロ相当の動作をブラウザで再現
日付 カテゴリ 内容・摘要 金額（税抜） 消費税

実装コード（Excel VBA）

入力シートから帳票シートへデータを転記し、合計・税額を自動計算。フォーマット設定・印刷まで一括実行します。

' Excel VBA - 経費精算書自動生成マクロ
Sub GenerateExpenseReport()
    Dim ws As Worksheet
    Dim reportWs As Worksheet
    Dim lastRow As Long
    Dim total As Long
    Dim taxTotal As Long

    Set ws = ThisWorkbook.Sheets("入力シート")

    ' 既存のレポートシートを削除して再作成
    Application.DisplayAlerts = False
    On Error Resume Next
    ThisWorkbook.Sheets("経費精算書").Delete
    On Error GoTo 0
    Application.DisplayAlerts = True

    Set reportWs = ThisWorkbook.Sheets.Add(After:=ws)
    reportWs.Name = "経費精算書"

    ' ヘッダー設定
    With reportWs
        .Cells(1, 1).Value = "経費精算書"
        .Cells(1, 1).Font.Size = 18
        .Cells(1, 1).Font.Bold = True
        .Cells(3, 1).Value = "申請日:"
        .Cells(3, 2).Value = ws.Cells(2, 2).Value
        .Cells(4, 1).Value = "申請者:"
        .Cells(4, 2).Value = ws.Cells(3, 2).Value
    End With

    ' 明細行を転記
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
    Dim reportRow As Integer
    reportRow = 7

    For i = 2 To lastRow
        If ws.Cells(i, 1).Value <> "" Then
            reportWs.Cells(reportRow, 1).Value = ws.Cells(i, 1).Value
            reportWs.Cells(reportRow, 2).Value = ws.Cells(i, 2).Value
            reportWs.Cells(reportRow, 3).Value = ws.Cells(i, 3).Value
            reportWs.Cells(reportRow, 4).Value = ws.Cells(i, 4).Value
            Dim taxRate As Double
            taxRate = 0.1  ' 消費税10%
            reportWs.Cells(reportRow, 5).Value = ws.Cells(i, 4).Value * taxRate
            total = total + ws.Cells(i, 4).Value
            taxTotal = taxTotal + ws.Cells(i, 4).Value * taxRate
            reportRow = reportRow + 1
        End If
    Next i

    ' 合計行
    reportWs.Cells(reportRow + 1, 3).Value = "合計（税抜）"
    reportWs.Cells(reportRow + 1, 4).Value = total
    reportWs.Cells(reportRow + 2, 3).Value = "消費税（10%）"
    reportWs.Cells(reportRow + 2, 5).Value = taxTotal
    reportWs.Cells(reportRow + 3, 3).Value = "合計（税込）"
    reportWs.Cells(reportRow + 3, 4).Value = total + taxTotal
    reportWs.Cells(reportRow + 3, 4).Font.Bold = True
    reportWs.Cells(reportRow + 3, 4).Font.Size = 14

    ' 書式設定
    reportWs.Columns("D:E").NumberFormat = "¥#,##0"
    reportWs.Columns.AutoFit

    MsgBox "経費精算書を作成しました。", vbInformation
    reportWs.Activate
End Sub
実装ポイント
・入力シートと出力シートを分離することで、再生成を何度でも実行可能
・カテゴリ別に税率を変えたい場合（軽減税率8%等）は taxRate の条件分岐で対応
・月次バッチでは Application.ScreenUpdating = False で高速化
