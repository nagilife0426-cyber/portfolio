仕事の進め方

3ステップで完結

要件のすり合わせから納品まで、シンプルなフローで進めます。

01

叩き台提案

「こんなことできますか？」という段階でOKです。 業務内容をヒアリングし、自動化できる範囲と費用感を まずお伝えします。叩き台のサンプルコードを作ることもあります。

// ヒアリング → 概算見積もり
02

要件確定

入力データの形式・操作手順・エラー時の動作など 細かな仕様を確認します。後から「想定と違った」が 起きないよう、認識のずれをここで潰します。

// 仕様書 → 金額確定 → 着手
03

納品

コード本体＋使い方ドキュメントをセットで納品します。 「自分で少し変更できる」ようにコメントを丁寧に書きます。 修正対応もお気軽にご相談ください。

// コード + ドキュメント納品
